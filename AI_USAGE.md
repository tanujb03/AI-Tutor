# AI Tools & Technology Usage Disclosure

This document outlines the AI tools and platforms utilized during the ideation, design, asset creation, and implementation of the AI Tutor application.

## 1. Google Antigravity IDE
- **Role**: Primary development platform and pair-programming environment.
- **Usage**: Used for end-to-end code development, component architecture, terminal execution, real-time Vite build verification, automated testing against mock scenarios, and refactoring.

## 2. Google Stitch
- **Role**: UI design system and screen layout generation.
- **Usage**: Used to define the dark theme design system (`DESIGN.md`), component color tokens (`#131313` dark surface, HSL primary accents), 4px border radii (`rounded`, `0.25rem`), typography hierarchy (Inter and JetBrains Mono), and desktop split-screen layout.

## 3. Google Mixboard
- **Role**: Concept brainstorming and visual theme exploration.
- **Usage**: Used for initial visual theme exploration, establishing the aesthetic direction, and ideating the dark academia / research assistant interface style.

## 4. Claude (Anthropic)
- **Role**: Pedagogical feature ideation and requirement analysis.
- **Usage**: Used for brainstorming pedagogical assistant feature sets, analyzing prompt scenarios, structuring the coverage map logic, and refining user flow requirements (before-asking state, citation grounding, exam revision deck).

## 5. Gemini (Google)
- **Role**: Visual asset and image generation.
- **Usage**: Used for generating high-resolution logo artwork, course identity assets, and emblem imagery for the header, favicon, and lightbox overlays.
